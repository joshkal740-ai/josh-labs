JOSH Labs — site web

Fichier principal : index.html
Langue par défaut : français.
Le sélecteur Google Traduction permet de choisir parmi de nombreuses langues. La traduction nécessite une connexion Internet.

Pour publier avec GitHub Pages : téléversez index.html à la racine du dépôt, validez le commit, puis activez Settings > Pages > Deploy from a branch > main > /(root).

Avant publication, remplacez l’adresse e-mail de démonstration hello@josh-labs.example par une adresse réelle.
